API Reference

You can use these API endpoints to access information such as Google Play / App Store reviews, related keywords, category rankings, downloads/revenues, and other app data. Click on the APIs to get more information on each available endpoint.

You can try each endpoint in this reference documentation to receive a sample request URL and response body.
Click "Try it out" on the endpoint you want to try, adjust the parameters as necessary and hit "Execute".

Each request must be authorized with auth_token parameter. You can generate your auth token on your account profile (API Settings tab).

In the response, you will have 2 headers:

  • x-api-usage-limit - current API monthly limit per organization
  • x-api-usage-count - current API monthly usage per organization

Your browser may not be able to load a large response on this page. Please try with a small date range and or apps / countries combination to see the sample responses. If you want to see a larger sample response, you can use your default API client of choice.

Rate Limit: 6 requests per second.

Requests should be made to the following base URL, followed by the specific path to the API you want to use.

Base URL: https://api.sensortower.com

## Direction

An original, dense production control room: the source material, shot canvas, and Linglong Copilot remain visible together so a producer can make a deliberate decision without changing context.

## Page composition

1. Fixed top rail: Linglong Studio identity, six production stages, team controls.
2. Fixed left project tree: project, brief, assets, reusable people/locations/products, and shots.
3. Center production canvas: selected shot, storyboard/take/version tabs, visual evidence, editable image and motion prompt fields, and a deliberate primary generation control.
4. Fixed right Copilot: readable plan/actions, confirmation controls, and an input composer.

## Fixed rules

- Three-column desktop workspace with 1px dividers, no floating browser shell.
- Purple is reserved for the active generation decision; green only communicates completion.
- The generation call to action always names the specific output being created.
- Prompt and version controls stay attached to the selected shot.
- The product owns its names, copy, icons, assets, and brand mark; no ArcReel source code, logo, screenshots, characters, images, or proprietary text ships.
- Novel adaptation is absent. The project entry points are commercial video, original short drama, video repair, and CTV.

# 02 — CTV 电商创意研究与创意系统决策

## 目的

将样本研究和客户一手资料转成可制作、可审核的广告创意系统。重点是找到会带来注意力和信任的**创意机制**，不是照抄竞品广告。

## 输入

- 《01 — CTV 平台与视频样本研究》的 5 条样本表与结论。
- 《03 — 电商客户官网素材采集》的产品、品牌、素材和已证实主张。
- 市场、媒体环境、片长、画幅、转化目标、落地页、预算与必需免责声明。

## 从样本中提炼机制

把每一条观察转换成“机制”，而不是某支视频的外观。

| 原始观察 | 可迁移机制 | 禁止的错误做法 |
|---|---|---|
| 镜头一开始就展示窗帘开合 | 先展示可见结果，再解释产品 | 复刻同一房间、构图或文案 |
| 评测者先说安装担忧再实际操作 | 用一个真实异议引出可见证明 | 把评测者的评价当作客户产品事实 |
| 品牌片用自然光改变空间情绪 | 用环境转变承载功能利益 | 用竞品的配乐、调色或镜头序列 |

将所有样本归类并统计：Hook 类型、产品证明类型、场景、创意形式、CTA 和未解决异议。若某模式只出现一次，不能把它当成行业规律。

## 为 CTV 选择正确的内容组合

不要让一支片承担所有任务。默认为新兴或成长型电商品牌配置以下组合：

| 交付物 | 作用 | 推荐形式 |
|---|---|---|
| CTV 主片 | 让受众理解并想拥有产品 | 30–60 秒、16:9、一个情绪或实用转变、少字且无声可懂 |
| 功能证明短片 | 快速消除一项购买阻力 | 6/15 秒、一个卖点、真实演示、横竖版可改编 |
| Creator / Expert 变体 | 增加可信度和考虑度 | 15–30 秒、真实问题 + 操作 + 结果；主要用于 Meta/TikTok/YouTube 社媒位 |
| 叙事片 | 放大独特的人类张力 | 只在问题无法靠产品演示表达时使用；不为“电影感”硬加剧情 |

对于 Roku、Pluto 等 CTV：优先让空间、光线、人物行为和产品动作说话；人物可以提供生活尺度，但不应成为长时间对镜讲解的主体。

## 创意决策模板

```markdown
# [品牌] [产品] CTV 创意 Brief

## 目标
- 市场与投放：
- 目标受众：
- 业务动作：
- 主片长度 / 画幅：

## 已证实的产品事实
- [事实 + 一手来源 URL]

## 核心张力
- 受众在什么时刻遇到什么问题？

## 创意承诺
- 用一句不夸张、可证明的话描述结果。

## 可见证明
- 观众具体会看到什么动作、变化或细节？

## 创意结构
1. 0–2 秒：
2. 问题 / 欲望：
3. 产品动作与证据：
4. 生活或情绪结果：
5. 品牌与 CTA：

## 需避免
- 未核验主张：
- 竞品相似风险：
- 品牌禁用元素：

## 衍生版本
- 6 秒：
- 15 秒：
- Creator / 竖版：
```

## 通过门槛

在进入脚本与分镜前确认：首两秒已写清楚；每一个关键主张都有一手来源；产品证明是可拍或可生成的；品牌/CTA 在大屏上可读；并且明确哪些素材和句子不能使用。若其中任一项缺失，应回到样本研究或官网素材采集，而不是开始生成。

# 03 — 电商客户官网素材采集与 Brand/Product Asset Manifest

## 目的

将客户独立站的公开一手信息整理成广告制作可用的品牌与产品资产清单。结果应让创意、分镜、生成和剪辑团队知道：推广什么、哪些事实可说、哪些现有素材可用、哪些内容必须补拍或生成。

## 范围与权限

- 只访问客户授权、公开可访问且符合网站条款的页面。
- 不绕过登录、付费墙、反自动化机制、robots 限制或下载保护。
- 优先保存 URL、页面截图/缩略图和元数据；下载或在广告中使用文件前，确认客户拥有或授权相应的使用权。
- 产品评价可用于发现问题与语言；不能把单条用户评论改写为产品性能保证。

## 采集顺序

1. **确认业务任务**：市场、投放渠道、主转化、推广品类、可使用的品牌资产范围。
2. **品牌页**：首页、About、FAQ、安装/支持、政策页；提取品牌定位、语气、禁用说法、售后和可信度线索。
3. **商品候选池**：从集合页、Best Sellers、评论排序、销售数据或客户指定规则中找 3–5 个候选 SKU。记录选择规则，不能把“评论多”写成“销量最高”，除非页面明示。
4. **主产品与辅助产品**：为每个候选审看 PDP、变体、图片、视频、规格、兼容性、安装、价格/促销、评论与 FAQ。
5. **素材盘点**：Logo、产品白底图、空间图、细节图、演示视频、UGC、安装素材、字体、颜色、音乐/肖像授权。
6. **事实核验与缺口**：给每个准备进入广告的主张附 URL；标出没有可靠来源、没有素材或需要客户确认的项目。

## 审核规则

- **产品图片不等于广告授权**：即使素材来自客户官网，也应由客户确认广告、区域、期限和编辑用途的授权范围。
- **价格、库存、促销和评论数字是易变信息**：每次发布前重新核验。
- **合规主张必须有来源**：静音、节能、遮光、安装时长、兼容性、儿童安全、医疗/健康等说法尤其需要逐条核验。
- **生成内容应参考真实产品素材**：颜色、织物、尺寸、控制器、Logo 和安装方式不能凭空补全。

## 交付到制作前的最小完成标准

必须确定一件主产品、可说明的核心利益、至少一个可见产品证明、品牌资产来源、CTA 与落地页；同时列明所有待确认事实和缺失素材。完成后将 Manifest 与《02 — CTV 电商创意研究》的 Brief 一并交给脚本/分镜阶段。

# 01 — CTV 平台与视频样本研究

## 目的

在创作脚本前，用少量可追溯的视频样本判断：什么样的开头、产品证明和画面语言适合目标市场的 CTV 广告。研究的目标是创意决策，不是证明竞品投放效果。

## 输入与默认范围

确认产品、市场、CTV 库存、转化目标、品牌资产和可用事实。

针对美国电商 CTV（例如 Roku、Pluto、YouTube CTV），默认只研究：

1. **YouTube**：品牌片、产品演示、安装与评测；用于判断横版主片和 6/15 秒功能短片。
2. **Meta Ads Library / Instagram Reels**：当前广告与真人创作者竖版表达。
3. **TikTok Creative Center / TikTok**：首秒 Hook、产品演示、用户疑问和交易语言。

Pinterest、Houzz、Amazon、Google Ads Transparency Center 等只在有明确缺口时加入，并在研究记录中说明原因。

## 首轮：五条，而非五个平台各五条

1. 用公开、可播放、与产品相关的样本建立候选池。
2. 优先审看 5 条能覆盖不同创意类型的样本：至少包含品牌/产品片和功能演示；如果全是评测或 UGC，补一条横版品牌片。
3. 用户要求“播放量最高”时，只能在可比较的**自然流量同平台池**内排序。通常会偏向 YouTube。
4. Meta Ads Library 通常没有可横向比较的播放量；TikTok 广告播放可能受预算影响。两者不能与 YouTube 合成一张“全平台播放量最高”榜。
5. 发布日期可得时，同时记录 views/day；高总播放量不自动代表更适合 CTV。

## 每条样本的必填记录

| 字段 | 记录方式 |
|---|---|
| ID | 例如 `YT-01`、`META-01`、`TT-01` |
| 市场 / 平台 / 形式 | 国家、频道或广告库、横竖比例、时长、自然内容/广告/评测/创作者 |
| 品牌与产品 | 广告主、商品、价位或品类（如公开可见） |
| 来源与日期 | 直接 URL、采集日期、是否需登录或播放受限 |
| 前 2 秒 Hook | 逐帧观察后写出首个画面、文字、台词和声音；不得从标题猜测 |
| 场景与人群 | 房间、使用时刻、人物角色、问题发生的环境 |
| 可见产品证明 | 真实运动、前后对比、安装、测量、材质、操作、评价；没有就写 `无` |
| 主信息 / 主张 | 尽量逐字；准备复用时标记“需客户一手资料验证” |
| CTA | 结尾画面或口播的原话；没有就写 `无` |
| 公开信号 | 播放、发布时间、点赞、收藏、评论、广告是否仍在投；不可得写 `不可得` |
| 评论主题 | 重复的问题、异议、信任语言；只记录主题，不用评论数判断好坏 |
| CTV 适配 | Hook、产品证明、可读性、品牌记忆、CTA 各 1–5 分及一句原因 |
| 可借鉴 / 不可复制 | 抽象机制，以及不能使用的画面、文案、主张或品牌资产 |

## 如何判断“值得借鉴”

公开互动只是一层发现信号。最终另行判断下列可观察维度：

| 维度 | 好的可观察信号 |
|---|---|
| 前两秒清晰度 | 不开声音也知道产品、变化或问题是什么 |
| 产品证明 | 真实展示产品在做事，而非只讲功能 |
| 电视可读性 | 大字、少信息、主体清楚、远距离仍能识别 |
| 品牌记忆 | 品牌与独特利益点有明确关联，而非最后一秒才出现 Logo |
| CTA 简洁度 | 一个可执行动作，没有复杂选择或长段说明 |

## 输出与停止条件

首轮输出应包括：样本表、来源链接、重复 Hook/证明模式、格式分布，以及“是否已经足够决定第一支片”的结论。

仅在以下情况扩展至 20–30 条：客户明确要求完整审计；五条未覆盖主要格式；或不同创意方向仍无法取舍。研究结束后交给《02 — CTV 电商创意研究》做创意系统决策。

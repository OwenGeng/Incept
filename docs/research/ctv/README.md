# CTV 电商视频研究与素材采集手册

这套手册用于 DTC / 电商客户的 CTV 广告前期工作。它不依赖某一个视频工具，可复制到任何项目；完成研究后，可把产物交给任意脚本、分镜、生成或剪辑工作流。

## 推荐顺序

```text
客户目标与投放信息
        ↓
01 平台与视频样本研究
        ↓
02 CTV 创意研究与创意系统决策 ← 03 官网素材采集
        ↓
可审核的创意 Brief / 脚本 / 分镜 / 制作
```

| 手册 | 解决的问题 | 主要产物 |
|---|---|---|
| [01 CTV 平台与视频样本研究](01-platform-research.md) | 去哪里找参考、如何判断哪些视频值得审看 | 带来源的 5 条首轮样本表、必要时扩展的候选池 |
| [02 CTV 电商创意研究](02-ecommerce-creative-research.md) | 如何把样本变成 CTV、功能短片与创作者内容的创意决策 | 创意机制总结、创意系统、可验证的 Brief |
| [03 电商客户官网素材采集](03-client-asset-intake.md) | 如何从客户独立站收集品牌、爆款商品、素材与可用事实 | Brand/Product Asset Manifest、主产品优先级、事实与风险清单 |

## 使用原则

- 先研究、再生成。没有来源和证据的“灵感”不能直接变成广告承诺。
- 默认首轮只审看 **5 条样本总数**，而非每个平台 5 条；只有决策仍不清楚时才扩展到 20–30 条。
- 不把公开播放、点赞、收藏、评论当成 CTV 效果。它们只用于发现内容和理解受众语言。
- 只借鉴可抽象的机制，例如“先展示运动结果，再说明功能”；不复制竞品画面、文案、音乐、商标或未证实主张。
- 只收集客户授权使用、公开可访问且符合网站条款的资料；记录来源 URL、采集日期和权利状态。

## 项目启动时需要的最小信息

1. 市场、语言、受众和投放渠道，例如美国 Roku / Pluto / YouTube CTV。
2. 成功事件，例如品牌认知、落地页访问、加购或购买。
3. 片长、画幅、落地页和 CTA。
4. 客户官网、品牌资产授权范围、禁用说法与必需免责声明。
5. 可优先推广的产品或选择规则，例如“按评论数排序的爆款”。

# 客户网站素材与 Moloco CTV 规格

## 使用入口

画布 → 素材库 → 客户网站素材。

输入客户官网、产品页面或官网热销页面的 HTTPS URL，点击“发现素材”。
最多选择20项，按每批12项导入；支持导入前公开素材预览，导入后可查看本地图片、播放视频、名称与描述、
打开来源网页、下载或添加到当前 Agent 输入框（不自动发送）。
文件存放在项目素材库的 `website/` 文件夹；刷新页面后目录仍保留。

Agent 工具：`website_assets_discover` → `website_assets_import`；
`list_website_assets` 可查找之前已采集的素材。仅询问能力时不应自动下载。
需要视频验收时调用 `validate_moloco_ctv_video`，输入项目 workspace 路径。

## 采集边界

### 出方案前的竞品研究确认

新客户 CTV 提案先显示聊天内的中英双语选择卡片：轻量（5条总样本）、
深度（20–30条）或暂不研究（仅客户官网）。确认前不调用模型或搜索工具。
问题保存于会话，当前连接正常结束；刷新可恢复待确认／已回答状态。
提交答案与恢复任务分别通过服务端验证，问题绑定用户、项目和会话，
恢复标识只消费一次。跳过按“不研究竞品”处理；关闭不算同意。
新消息使旧待确认问题失效；已确认方向的普通修改不重跑研究。

现有平台工具支持网页发现和公开字幕，不提供平台视频逐帧审看。
报告区分链接发现／字幕读取；不允许从标题、字幕伪造首两秒画面、
可见产品证明或视觉CTA。此类研究标注未完成项，但仍交付初步方案。
参考研究保存到 `research/video-sample-table.md`，竞品不能混入客户投放素材库。
轻量预算5次搜索、24次工具调用；深度预算10次搜索、60次工具调用。
预算或来源不足时交付缺口，不保证达到目标样本量、不绕过登录或视频保护。

- 发现 HTML img、lazy src、srcset、video/source、视频封面、网页图标、
  Open Graph 图片/视频和 JSON-LD Product / VideoObject / logo。
- 仅跟随网页中实际出现的同站 Best seller 链接及该页面的商品链接；
  最多检查12个页面；单页解码后HTML上限8MB、合计32MB、采集时间预算90秒。
  指定商品页时不跟随其他SKU链接；主商品图集保留商品页归属，优先保留商品图与视频。
  目录最多200项，不猜测私有API或商品销量排名。
- 支持懒加载视频直链；候选数量不是独立高清图数量，也不代表已下载或完成质检。
  商品素材请求不能只导入Logo就宣称完成；Agent分批导入，分别报告商品图、视频、
  品牌素材及未完成原因。实际可用数量取决于官网，不保证固定数量。
- 名称/描述来自页面元数据、alt、JSON-LD，不是视觉识别结论。
- 图片/Logo支持JPEG、PNG、GIF、WebP、AVIF；图标支持ICO；
  视频支持MP4、WebM、MOV直链。SVG保留发现记录但不导入，避免主动内容。
- 不执行JavaScript、不绕过登录/反爬/DRM，不下载播放器网页或HLS播放列表。
  视频未发现不表示官网没有视频；可提供具体产品页或客户原文件。
- 图片导入上限20MB、视频上限450MB、每批总量500MB，时间预算90秒。
  下载失败返回逐项原因；不保存不完整文件、不覆盖已有不同内容。
- 所有素材默认为广告授权待确认。公开可下载不等于有广告使用权。
- 下载/预览不代表Agent已经理解素材内容。需要“交给Agent”后发送问题；
  Gemini/OpenAI/Claude均可分析图片；450MB以内、180秒以内的视频可进入媒体准备。
  Gemini使用小原片、有界分析副本或现有私有存储引用；OpenAI/Claude仅接收带时间戳
  的采样帧，不包含音轨，也不是逐帧检查。处理失败/超预算会明确说明未分析原因。
  以上是应用准入，并非已验证的Cloud Run大文件上传承诺；部署入口仍需单独验收。

## Moloco 规格（2026-10-08核对）

按用户提供的CTV客户配置接入：16:9 MP4，推荐1920×1080、接受1280×720，
24 FPS及以上，最大450MB，时长6–180秒，推荐15/30/60秒。
MB使用十进制字节，不与附件分析的MiB限制混用。

来源：[通用视频指南](https://help.moloco.com/hc/en-us/articles/7104841219095-Video-creative-guide)。
该文支持MP4、24 FPS以上、450MB和6–180秒；它不是专门的CTV库存验收标准。
通用End card规则为JPEG/JPG/PNG/GIF、与视频方向一致、宽高均至少320px、
最大500KB（GIF最大1MB）；是否用于独立CTV End card需另行确认。

客户已经确认以上配置，`approval_status` 为 `customer_configuration_confirmed`。
它是本项目的技术验收依据；其他公开投放页面仅作背景参考，不得覆盖客户
配置、额外限制文件大小或时长，也不再要求用户重复确认已确认的规格。
该配置不是对所有CTV交易所的普遍保证；通用指南的短视频循环策略不得默认套用。

视频检查通过ffprobe读取实际MP4封装、分辨率、帧率、时长和文件大小。
符合客户配置时返回 `technical_pass`，技术不合格时返回 `invalid`。
技术检查与广告使用权、平台审核分开：`approval_checks` 中后两项保持
`unverified`，`approved_for_delivery` 仍为 `false`，不以技术合格伪造投放批准。
需要部署环境提供ffprobe；不可用时返回未核验，不伪造通过结果。

## API与安全

接口均复用现有用户身份和项目隔离：

- `GET /video-legacy/api/assets/website?directory=...&offset=0&limit=100`
- `POST /video-legacy/api/assets/website/discover`：`{directory,url}`
- `POST /video-legacy/api/assets/website/import`：`{directory,asset_ids}`
- `GET /video-legacy/api/assets/creative-profile`
- `POST /video-legacy/api/assets/creative-check`：`{directory,path}`

目录保存在项目 `intake/website-assets.json`，真实文件在 `library/website/`。
来源URL、产品页、采集时间、sha256、实际文件格式、字节数与导入状态保留。
不存储账号密码、cookies或客户提供的网页登录凭证。

公网HTTPS与标准端口限定、所有DNS地址检查、连接IP固定、TLS主机验证保留，
防止DNS重绑定。二进制下载不跟随重定向；图片与视频校验文件签名，
按项目安全路径存储，使用临时文件及锁避免覆盖与损坏。
ffprobe只允许file/pipe协议，不允许媒体文件触发网络读取。

本次关联修复：当前问题置于Agent输入前部，Agent使用单独的较大文本预算；
纯聊天/素材采集的空operations不保存或替换画布。没有调整模型ID或云配置。
## 选择制作素材

从画布的 Open asset library（打开素材库）进入「客户网站素材」预览和选择；Agent 输入框不再放独立的选择入口或素材面板。按类型、状态、名称或商品链接筛选，每页 24 项，跨页最多选择 20 项。界面默认只展示简短操作与授权提醒，采集、分析及费用说明默认折叠。

公开素材可在导入前预览；远端访问/CORS/编码限制可能导致预览不可用，仍可导入后使用本地预览。视频 `preload=none`，播放前不预载整段视频。图片按需加载，不携带跨站凭证或 Referer。预览只涉及浏览器流量，不调用模型。

「导入选中素材」只下载缺失的所选文件，每批最多 12 项；部分批次失败保留已完成结果和选择，重试只导入剩余项。「所选素材添加到对话」先导入，再将成功文件加入当前 Agent 的附件草稿，**不会自动发送**；附件容量与分析限制仍由现有校验执行。只有发送分析请求时才产生模型媒体 token。未勾选素材不附加，导入/分析不代表进入成片。

素材名称、描述来自网站，不是画面分析结论；Agent 不应从文件名或商品图库归属推断特写、安装演示、镜头角度。用户确认的时长、帧率不能被默认推荐值替换。
